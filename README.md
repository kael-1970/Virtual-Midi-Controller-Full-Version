## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **MIDI Keyboard Simulation** — Use your computer's keyboard to generate and send MIDI data, making music production more accessible.
- **Customizable Interface** — Tailor the window layout to fit your workflow and preferences seamlessly.
- **Layer Control** — Manage multiple MIDI data layers, allowing for greater flexibility in your music production.
- **Adjustable MIDI Buffer** — Configure the MIDI buffer size for optimal data handling and performance.
